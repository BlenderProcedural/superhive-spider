# superhive-spider

A procedural walking spider for embedding in product pages via iframe.
It wanders inside its frame and chases the cursor on hover.

```html
<iframe src="https://blenderprocedural.github.io/superhive-spider/?bg=0b0b0f"
        width="100%" height="320" style="border:0" loading="lazy"></iframe>
```

URL options: `color=ff3344`, `bg=0b0b0f` (omit for transparent), `size=1`, `speed=1`.
